## Generative AI Reflection
**Tools used:** OpenCode Go GLM 5.3 Flash was used as the main workload for
building the website, alongside ChatGPT Go, and Google Stitch was used to
generate the website design from a written prompt.

**What GenAI was used for:** I used Generative AI to help create the design
prompt for the Stitch mock-up, to initialise the webpage structure (HTML,
CSS and JavaScript), and to debug the site together in an interactive
feedback loop, fixing visual glitches and errors as I found them.

**What I changed and adapted:** I reviewed and adjusted the generated output
before using it, changing small elements such as text content and
design details

**What I learnt:** The main thing I learnt was how to program JavaScript
using GenAI. Seeing how it explained JavaScript syntax to me helped me to
understand how the language works and how to teach the AI my problems
precisely so that it could help me effectively.

**Limitations and issues:** Because I had not used JavaScript before this
project, I sometimes found it difficult to fully understand the JavaScript
that was generated. At times I felt some burden when I could not interpret
the code on my own, so I used the AI as a teacher, asking it to explain
rather than simply accepting its code.
