# COS30045 Demonstration 2 – Exercises 4 to 6

Open `index.html` (the home page) to reach every exercise.

| Folder | Exercise | GitHub Classroom repo |
|---|---|---|
| `dv-04-svg-house/` | 4.1 SVG house | Exercise 4.1 |
| `dv-04-bar-chart-exercise/` | 4.3–4.7 horizontal bar chart (TV brand counts) | dv-04-bar-chart-exercise |
| `dv-05-multichart-webpage/` | 5.1 bar chart, 5.2 scatter + line chart, 5.3 donut chart | dv-05-multichart-webpage |
| `dv-06-interactivity/` | 6.1 histogram, 6.2 filter buttons (+ screen-size extension, histogram tooltip), 6.3 scatterplot + legend, 6.4 scatterplot tooltip | Exercise 6 |

Other folders:
- `knime/` – KNIME workflows (`2026 TV Data.knwf` makes the week 4 and week 5 CSVs) and the raw downloads from Canvas.
- `docs/` – GenAI declaration and Q&A notes. Not part of the websites.
- `_to_delete/` – old draft files, safe to delete.

Run locally: in this folder run `python3 -m http.server`, then open http://localhost:8000.
Opening the .html files directly will not work (browsers block d3.csv on file://) - use Live Server or the command above.
Shared theme (Ocean Depths colours, nav, buttons, chart cards) lives in `site.css`.
